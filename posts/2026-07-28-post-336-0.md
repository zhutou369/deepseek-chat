本文将详细指导您如何在 Raycast 中配置 DeepSeek API，实现全局 AI 查询、代码生成、文本总结等功能，显著提升您的工作效率。

## 准备工作：获取 DeepSeek API Key

要让 Raycast 与 DeepSeek 对话，首先需要一个 DeepSeek API Key。

1.  **访问 DeepSeek 平台**：
    打开浏览器，访问 DeepSeek 平台：[chat.deepseek.com](https://chat.deepseek.com)。
2.  **注册/登录账户**：
    如果您还没有账户，请注册一个；如果已有，直接登录。
3.  **前往 API Keys 页面**：
    登录后，通常可以在用户设置或 API 管理界面找到 `API Keys` 选项。
4.  **创建新的 API Key**：
    点击「创建新密钥」或类似按钮，生成一个新的 API Key。请务必妥善保管此密钥，因为它拥有访问您账户资源的权限。复制此密钥，后续配置 Raycast 时会用到。

## 安装与配置 Raycast Custom Command

Raycast 的强大之处在于其可扩展性。我们可以通过创建一个 "Custom Command"（自定义命令）来调用 DeepSeek API。

### 1. 安装 Raycast

如果您尚未安装 Raycast，请前往 Raycast 官网下载并安装。安装完成后，按 `Option + Space` (默认快捷键) 即可唤出 Raycast 搜索框。

### 2. 创建自定义脚本命令

我们将使用 Python 脚本来调用 DeepSeek API，因为 Python 在处理 JSON 和网络请求方面非常方便。

#### 步骤一：打开 Raycast 并创建 Custom Command

1.  唤出 Raycast 搜索框 (`Option + Space`)。
2.  输入 `Create Custom Command` 并选择该选项。
3.  在弹出的窗口中，选择 `Script Command` 类型。

#### 步骤二：配置脚本命令详情

根据以下提示填写或选择：

*   **Command Name**: `DeepSeek AI Chat` (或您喜欢的任何名称，这将是您在 Raycast 中搜索的关键词)
*   **Description**: `在 Raycast 中快速调用 DeepSeek AI 进行对话、编程或文本处理。`
*   **Keywords**: `deepseek, ai, chat, ask, code` (方便通过不同关键词搜索)
*   **Icon**: 选择一个合适的图标，例如一个机器人或对话气泡。
*   **Arguments**:
    *   **Title**: `Prompt`
    *   **Name**: `prompt`
    *   **Type**: `Text`
    *   **Placeholder**: `向 DeepSeek 提问...`
*   **Package Name**: `com.deepseek.raycast` (可选，但推荐规范化)
*   **Run in**: `Background`
*   **Output**: `Raw`
*   **Language**: `Python`
*   **Hotkeys**: 您可以为此命令设置一个全局快捷键，例如 `Ctrl + Shift + D`，这样就能一键唤出 DeepSeek。

#### 步骤三：编写 Python 脚本

在 `Script` 区域，粘贴以下 Python 代码。请注意将 `YOUR_DEEPSEEK_API_KEY` 替换为您在第一步中获取的实际 API Key。

```python
#!/usr/bin/env python3

import os
import sys
import json
import http.client

# 从 Raycast 环境变量获取 DeepSeek API Key
# 建议通过 Raycast 的 Preferences -> Extensions -> DeepSeek AI Chat -> Environment Variables 设置，而不是直接写在脚本里
# 如果直接写在脚本里，请务必注意信息安全
DEEPSEEK_API_KEY = os.environ.get("DEEPSEEK_API_KEY", "YOUR_DEEPSEEK_API_KEY_HERE")

# DeepSeek API 请求参数
# 您可以选择 deepseek-chat 或 deepseek-coder 等模型
MODEL_NAME = "deepseek-chat" # 或 "deepseek-coder"
API_HOST = "api.deepseek.com"
API_PATH = "/chat/completions"

def call_deepseek_api(prompt):
    conn = http.client.HTTPSConnection(API_HOST)
    headers = {
        'Content-Type': 'application/json',
        'Authorization': f'Bearer {DEEPSEEK_API_KEY}'
    }

    payload = json.dumps({
        "model": MODEL_NAME,
        "messages": [
            {"role": "user", "content": prompt}
        ],
        "stream": False # Raycast Script Command 通常不需要流式输出
    })

    try:
        conn.request("POST", API_PATH, payload, headers)
        res = conn.getresponse()
        data = res.read()
        conn.close()

        if res.status == 200:
            response_json = json.loads(data.decode("utf-8"))
            if "choices" in response_json and len(response_json["choices"]) > 0:
                print(response_json["choices"][0]["message"]["content"])
            else:
                print("Error: No choices found in DeepSeek API response.")
        else:
            print(f"Error: DeepSeek API returned status {res.status} - {data.decode('utf-8')}")
    except Exception as e:
        print(f"An error occurred: {e}")

if __name__ == "__main__":
    if len(sys.argv) > 1:
        # sys.argv[1] 是 Raycast 传递的第一个参数，即我们的 prompt
        user_prompt = sys.argv[1]
        call_deepseek_api(user_prompt)
    else:
        print("Usage: Call this script with a prompt argument.")
        print("Example: raycast-script DeepSeek AI Chat '用 Python 写一个快速排序算法'")

```

**重要提示：关于 API Key 安全**

为了安全起见，强烈建议将 `DEEPSEEK_API_KEY` 设置为 Raycast Custom Command 的环境变量。

*   在 Raycast Preferences (快捷键 `Cmd + ,`) 中，找到 `Extensions`。
*   搜索 `DeepSeek AI Chat` (您的自定义命令名称)。
*   点击命令右侧的齿轮图标进入设置。
*   在 `Environment Variables` (环境变量) 部分，添加一个名为 `DEEPSEEK_API_KEY` 的变量，其值就是您的 DeepSeek API Key。
*   然后将脚本中的 `DEEPSEEK_API_KEY = os.environ.get("DEEPSEEK_API_KEY", "YOUR_DEEPSEEK_API_KEY_HERE")` 行修改为 `DEEPSEEK_API_KEY = os.environ["DEEPSEEK_API_KEY"]`，或者移除 `,"YOUR_DEEPSEEK_API_KEY_HERE"` 部分，只保留 `os.environ.get("DEEPSEEK_API_KEY")`。这样可以避免硬编码密钥到脚本中。

### 3. 保存并测试

点击 `Create Command` 保存您的自定义命令。现在，您可以：

1.  按下 Raycast 快捷键 (`Option + Space`)。
2.  输入 `DeepSeek AI Chat` (或您为命令设定的名称)。
3.  在出现的提示框中输入您的问题或指令，例如 `用 Python 写一个斐波那契数列的函数`。
4.  按下 `Enter` 键。Raycast 会执行脚本，并在几秒钟内（取决于网络和 DeepSeek API 响应速度）在 Raycast 搜索框下方显示 DeepSeek 的回复。
