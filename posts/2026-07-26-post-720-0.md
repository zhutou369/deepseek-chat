实时互动是直播的灵魂，但长时间的直播互动对主播来说是巨大的挑战。利用 [DeepSeek API](https://chat.deepseek.com) 的强大能力和 OBS Studio 的灵活推流功能，您可以搭建一个能够自动响应观众、提供实时互动的 AI 直播间，实现无人值守的智能直播体验。

## 1. 准备工作：环境与 DeepSeek API 密钥

在开始之前，确保您的开发环境已准备就绪。

### 1.1 安装必要软件与库

您需要安装以下工具和库：

*   **OBS Studio:** 用于直播推流和画面合成。请从 [OBS 官网](https://obsproject.com/) 下载并安装。
*   **Python 3.x:** 作为主要编程语言。
*   **Python 依赖库:**
    *   `requests`: 用于调用 DeepSeek API。
    *   `python-dotenv`: 用于安全地加载环境变量（如 API 密钥）。
    *   `gTTS`: 用于将文本转换为语音（Text-to-Speech）。
    *   `playsound`: 用于播放生成的语音文件。

您可以通过以下命令安装 Python 库：

```bash
pip install requests python-dotenv gTTS playsound
```

### 1.2 获取 DeepSeek API 密钥

访问 [DeepSeek 官网](https://chat.deepseek.com)，登录您的账户。在用户中心的 API 管理页面，您可以创建并获取您的 API 密钥。请妥善保管此密钥，切勿直接暴露在代码中。

为了安全起见，建议使用 `.env` 文件来存储您的 API 密钥。在项目根目录创建 `.env` 文件，内容如下：

```dotenv
DEEPSEEK_API_KEY="YOUR_DEEPSEEK_API_KEY"
```

## 2. OBS Studio 配置：直播画面与文本展示

接下来，我们将配置 OBS Studio 来捕获 AI 的输出并将其显示在直播画面中。

### 2.1 创建直播场景

打开 OBS Studio，在“场景”面板中点击“+”创建一个新场景，例如命名为“AI 直播间”。

### 2.2 添加 AI 文本输出源

为了让观众看到 AI 的回复，我们需要一个文本源来动态显示内容。

1.  在“源”面板中，点击“+”，选择“文本 (GDI+)”。
2.  创建一个新源，命名为“AI 回复文本”。
3.  在弹出的属性窗口中，勾选“从文件读取”。
4.  点击“浏览”，选择一个我们将用于 AI 输出的文件。例如，在您的项目目录中创建一个 `ai_response.txt` 文件。
5.  配置字体、颜色和大小，使其在直播画面中清晰可见。
6.  将文本框放置在直播画面中合适的位置。

![OBS Studio 文本源配置](/static/posts/covers/step-guide.svg)

### 2.3 设置音频输出

为了让观众听到 AI 的声音，您需要确保您的系统音频被 OBS 捕获。

1.  在“混音器”面板中，确保“桌面音频”或您正在使用的音频输出设备处于激活状态。
2.  您可以调整其音量，确保 AI 语音清晰可闻。

### 2.4 配置直播推流

在 OBS “设置” -> “推流”中，选择您的直播平台（如 Twitch、YouTube 等），并填写您的直播推流码。完成后点击“开始推流”，您的 OBS 就能将画面推送到直播平台。

## 3. Python 脚本核心逻辑：DeepSeek 交互与内容生成

现在，我们将编写 Python 脚本来驱动 AI 互动逻辑。

### 3.1 DeepSeek API 交互函数

首先，编写一个函数来调用 DeepSeek API 获取回复。我们将使用 `deepseek-chat` 模型，并实现简单的多轮对话记忆。

```python
import os
import requests
from dotenv import load_dotenv
from gtts import gTTS
from playsound import playsound
import time

load_dotenv() # 加载 .env 文件中的环境变量

DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY")
API_BASE_URL = "https://api.deepseek.com/chat/completions" # DeepSeek API 基础URL

# 用于存储对话历史，实现多轮记忆
conversation_history = [
    {"role": "system", "content": "你是一个友善且乐于助人的直播AI助手，会用轻松愉快的语气与观众互动，回答他们的问题。你的名字叫小深。"}
]

def get_deepseek_response(user_message):
    global conversation_history
    conversation_history.append({"role": "user", "content": user_message})

    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
    }
    data = {
        "model": "deepseek-chat", # 使用 deepseek-chat 模型
        "messages": conversation_history,
        "stream": False # 非流式请求
    }

    try:
        response = requests.post(API_BASE_URL, headers=headers, json=data)
        response.raise_for_status() # 检查HTTP请求是否成功
        result = response.json()
        
        # 提取AI的回复
        ai_response_content = result["choices"][0]["message"]["content"]
        conversation_history.append({"role": "assistant", "content": ai_response_content}) # 添加AI回复到对话历史
        
        # 限制对话历史长度，防止内存溢出和API请求过大
        # 例如，保留最后5轮对话 (系统消息 + 5用户 + 5助手 = 11条，所以限制10条保留5轮)
        if len(conversation_history) > 11: 
            conversation_history = [conversation_history[0]] + conversation_history[-10:] 
            
        return ai_response_content
    except requests.exceptions.RequestException as e:
        print(f"DeepSeek API 请求失败: {e}")
        return "抱歉，我暂时无法回答您的问题。"
    except KeyError as e:
        print(f"DeepSeek API 返回数据格式错误: {e}")
        print(f"原始响应: {response.text}")
        return "抱歉，AI服务返回了意外的数据。"
```
关于如何更好地管理对话历史，您可以参考 [/posts/deepseek-multi-turn-memory/](/posts/deepseek-multi-turn-memory/)。

### 3.2 文本转语音与播放

使用 `gTTS` 和 `playsound` 将 AI 的文本回复转换为语音并播放。

```python
def text_to_speech_and_play(text, lang='zh-cn'):
    try:
        tts = gTTS(text=text, lang=lang)
        audio_file = "ai_response.mp3"
        tts.save(audio_file)
        playsound(audio_file)
        os.remove(audio_file) # 播放后删除临时文件
    except Exception as e:
        print(f"语音合成或播放失败: {e}")
```

### 3.3 OBS 文本文件更新

我们将 AI 的回复写入一个文本文件，OBS 会自动读取并显示。

```python
def update_obs_text_file(content, filename="ai_response.txt"):
    try:
        with open(filename, "w", encoding="utf-8") as f:
            f.write(content)
        print(f"OBS 文本文件 '{filename}' 已更新。")
    except Exception as e:
        print(f"更新 OBS 文本文件失败: {e}")
```

### 3.4 模拟观众输入与主循环

为了简化教程，我们使用一个 `chat_input.txt` 文件来模拟观众输入。您可以手动向这个文件写入内容，脚本会读取并处理。

```python
# 文件路径定义
CHAT_INPUT_FILE = "chat_input.txt"
OBS_OUTPUT_FILE = "ai_response.txt"

def read_new_chat_input(filename):
    """读取新的聊天输入，并清空文件"""
    if not os.path.exists(filename):
        # 如果文件不存在，则创建它
        with open(filename, "w", encoding="utf-8") as f:
            pass
        return None
    
    with open(filename, "r+", encoding="utf-8") as f:
        content = f.read().strip()
        if content:
            f.seek(0)
            f.truncate() # 清空文件内容
            return content
    return None

def main_loop():
    print("AI 直播间助手已启动，等待观众输入...")
    update_obs_text_file("AI助手已就绪，欢迎提问！", OBS_OUTPUT_FILE) # 初始提示

    while True:
        user_input = read_new_chat_input(CHAT_INPUT_FILE)
        if user_input:
            print(f"收到观众消息: {user_input}")
            # 1. 调用 DeepSeek API 获取回复
            ai_response = get_deepseek_response(user_input)
            print(f"AI 回复: {ai_response}")

            # 2. 更新 OBS 显示文本
            update_obs_text_file(ai_response, OBS_OUTPUT_FILE)

            # 3. 播放 AI 语音
            text_to_speech_and_play(ai_response)
        
        time.sleep(2) # 每2秒检查一次新的聊天输入

if __name__ == "__main__":
    main_loop()
```
您可以手动向 `chat_input.txt` 中写入观众想问的问题，例如：

```
你好，小深！你今天心情怎么样？
```

### 3.5 运行脚本

在您的终端中运行 Python 脚本：

```bash
python your_ai_livestream_script.py
```

当脚本运行时，它会监听 `chat_input.txt` 文件的变化。一旦有新内容写入，它会触发 AI 响应并更新 OBS。

## 4. 扩展与优化

这个基础框架可以根据您的需求进行扩展和优化。

*   **真正的直播平台聊天集成:** 将 `read_new_chat_input` 函数替换为集成 Twitch、YouTube 等平台的聊天 API，实时获取观众消息。这将是实现完全无人值守的关键一步。
*   **AI 角色定制:** 通过调整 DeepSeek API `messages` 参数中的 `system` 角色设定，让 AI 拥有更具特色的人格。更多关于角色设定的技巧，请参考 [/posts/deepseek-chat-scenario-library/](/posts/deepseek-chat-scenario-library/)。
*   **语音识别 (ASR):** 如果希望 AI 也能“听”到观众的声音（例如通过麦克风输入），可以集成语音识别技术。
*   **多媒体内容生成:** DeepSeek API 也可以生成代码、创意文本等，您可以利用这些能力让 AI 在直播中展示更多样化的内容。
*   **错误处理与日志记录:** 增加更完善的错误处理和日志记录机制，确保直播间的稳定运行。
