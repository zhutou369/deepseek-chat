智能家居的未来在于更自然、更智能的交互方式。Home Assistant (HA) 提供了强大的本地控制能力，而 DeepSeek 等大型语言模型则擅长理解和执行复杂的自然语言指令。将两者结合，可以实现前所未有的智能控房体验。本文将指导您完成 Home Assistant 接入 DeepSeek 的全过程，让您的家听懂你的话。

## 准备工作：DeepSeek API 密钥与 Home Assistant

在开始之前，确保您已完成以下准备：

1.  **Home Assistant 运行环境：** 您的 Home Assistant 实例需要正常运行并可通过本地网络访问。无论是运行在树莓派上的 Home Assistant OS，还是 Docker 容器，亦或是其他安装方式，只要能正常访问 Web 界面即可。
2.  **可控设备：** 确保 Home Assistant 中已接入并可控制至少一个智能设备（如智能灯泡、开关、空调、窗帘等）。这些设备的实体 ID (Entity ID) 是后续 DeepSeek 识别和控制的关键。
3.  **DeepSeek API 密钥：**
    *   访问 DeepSeek 平台 (例如 `chat.deepseek.com` 或其开发者入口)。
    *   注册并登录您的账户。
    *   在账户设置或 API 管理页面找到并生成您的 API 密钥。
    *   **请妥善保管此密钥，切勿泄露。**

    ![DeepSeek API Key Acquisition Example](/static/posts/covers/step-guide.svg)

## 步骤一：配置 Home Assistant 的 OpenAI Conversation 集成

DeepSeek API 兼容 OpenAI API 规范，这意味着我们可以利用 Home Assistant 内置的 `OpenAI Conversation` 集成来实现快速连接。

1.  **进入集成配置界面：**
    *   打开 Home Assistant Web 界面。
    *   点击侧边栏的 **“设置”** (Settings)。
    *   选择 **“设备与服务”** (Devices & Services)。
    *   点击右下角的 **“添加集成”** (Add Integration)。
2.  **搜索并添加集成：**
    *   在搜索框中输入 `OpenAI Conversation`。
    *   点击搜索结果中的 `OpenAI Conversation`。
3.  **填写配置信息：**
    *   **“对话助手的名称”** (Name)：您可以自定义一个名称，例如 `DeepSeek 智能助理`。
    *   **“API 密钥”** (API Key)：粘贴您从 DeepSeek 获取的 API 密钥。
    *   **“API 端点”** (API Endpoint)：填写 DeepSeek 的 API 地址，通常是 `https://api.deepseek.com/v1`。
    *   **“模型”** (Model)：填写您希望使用的 DeepSeek 模型名称，例如 `deepseek-coder` 或 `deepseek-chat`。
        *   **注意：** 请根据 DeepSeek 官方文档确认当前可用的模型名称及其支持的功能。通常 `deepseek-chat` 模型更适合日常对话和智能家居控制。
    *   **“温度”** (Temperature)：控制模型输出的随机性，建议设为 `0.5` 到 `0.7` 之间，以获得更稳定且富有创意的回复。
    *   **“最大令牌数”** (Max tokens)：每次请求返回的最大令牌数，可以根据需求设置，例如 `250`。
    *   **“系统提示”** (System Prompt)：这是最关键的部分，它定义了 DeepSeek 的角色和行为。我们将在此处告诉 DeepSeek 它是智能家居助手，以及它能控制哪些设备。

    ![Home Assistant Integration Setup](/static/posts/covers/step-guide.svg)

## 步骤二：精心编写系统提示 (System Prompt)

系统提示 (System Prompt) 决定了 DeepSeek 理解和响应自然语言指令的能力。一个好的提示应该明确告诉 DeepSeek 它的职责、可用的工具（即 Home Assistant 服务）以及如何使用它们。

以下是一个推荐的系统提示模板，您可以根据自己的设备和需求进行修改：

```yaml
你是 Home Assistant 智能家居的 AI 助手。你的目标是根据用户的指令控制智能设备，并提供必要的信息。
你拥有以下能力：
- `turn_on`：打开设备或场景。
- `turn_off`：关闭设备或场景。
- `toggle`：切换设备状态。
- `set_brightness`：设置灯光的亮度。
- `set_temperature`：设置空调或暖气的温度。
- `open_cover`：打开窗帘。
- `close_cover`：关闭窗帘。

你可控制的设备列表（及其别名）：
- 客厅灯 (light.living_room_light)
- 卧室灯 (light.bedroom_light)
- 空调 (climate.air_conditioner)
- 窗帘 (cover.bedroom_curtain)
- 电视 (media_player.living_room_tv)
- 观影模式 (scene.movie_night)

**指令说明：**
- 当用户要求控制设备时，请直接调用 Home Assistant 的服务。
- 当用户要求查询设备状态时，如果无法直接获取，请礼貌地告知用户。
- 如果用户指令不明确，请主动询问，例如：“您想打开客厅的哪盏灯？”
- 优先使用设备别名，但也要能识别实体ID。

**重要提示：**
- **不要回复与智能家居控制无关的内容。**
- **只使用上面列出的设备和服务。**
- **回答简洁明了，无需多余的寒暄。**

例如：
用户说：“打开客厅灯”
你应执行：
```json
{
  "service": "light.turn_on",
  "target": {
    "entity_id": "light.living_room_light"
  }
}
```

用户说：“把空调温度设到25度”
你应执行：
```json
{
  "service": "climate.set_temperature",
  "target": {
    "entity_id": "climate.air_conditioner"
  },
  "data": {
    "temperature": 25
  }
}
```
```

**提示编写要点：**

*   **明确角色：** 一开始就告诉 DeepSeek 它的身份和任务。
*   **列出服务：** 明确 DeepSeek 可以调用的 Home Assistant 服务（`light.turn_on`, `climate.set_temperature` 等）。
*   **列出设备及 ID：** 这是核心。将您的设备实体 ID 及其常用别名列出来，让 DeepSeek 知道它能控制什么。您可以在 Home Assistant 的 `开发者工具` -> `状态` 中找到所有设备的实体 ID。
*   **行为准则：** 告诉 DeepSeek 如何响应不明确的指令、如何保持简洁等。
*   **示例：** 提供具体的输入和 DeepSeek 应该生成的 Home Assistant 服务调用的 JSON 示例，这对于 DeepSeek 理解格式和意图至关重要。

如果您想深入了解如何为 AI 助手设计更有效的对话场景和提示词，可以参考这篇关于 [DeepSeek Chat 场景库与提示词应用](https://aigc.ai/posts/deepseek-chat-scenario-library/) 的教程。

## 步骤三：测试 DeepSeek 智能助理

配置完成后，就可以开始测试您的智能家居助理了。

1.  **使用 Home Assistant 对话功能：**
    *   在 Home Assistant 侧边栏找到 **“对话”** (Conversation) 图标。
    *   在对话框中输入您的指令，例如：“打开客厅灯”、“把卧室灯亮度调到50%”、“关闭空调”等。
    *   观察 Home Assistant 是否正确识别指令并执行操作。
2.  **检查日志：** 如果遇到问题，可以查看 Home Assistant 的日志 (`设置` -> `系统` -> `日志`)，通常会有助于诊断错误。
3.  **调整提示词：** 如果 DeepSeek 无法正确理解某些指令或执行错误的操作，请回到步骤二，仔细检查并优化您的系统提示词，尤其是设备名称、别名和示例。

## 步骤四：通过语音助手或自动化触发

一旦 DeepSeek 智能助理在 Home Assistant 中运行良好，您可以将其与更多交互方式结合：

*   **Home Assistant 移动应用：** 您可以通过 Home Assistant 的官方移动应用直接与 DeepSeek 助理对话。了解更多移动应用的使用技巧，可以查看 [DeepSeek 移动应用聊天指南](https://aigc.ai/posts/deepseek-mobile-app-chat/)。
*   **Google Assistant / Amazon Alexa：** 如果您使用了 Nabu Casa 云服务或者通过 DuckDNS/SSL 配置了外部访问，可以将 Home Assistant 集成到 Google Assistant 或 Amazon Alexa。这样，您就可以直接通过智能音箱向 DeepSeek 发送语音指令。
*   **自动化脚本：** 对于一些复杂或多步骤的操作，您可以创建 Home Assistant 脚本 (Scripts) 或自动化 (Automations)。例如，创建一个名为 `观影模式` 的脚本，当 DeepSeek 接收到“启动观影模式”的指令时，可以触发这个脚本来同时关闭窗帘、调暗灯光、打开电视等。

    *   在 Home Assistant 中，进入 `设置` -> `自动化与场景` -> `脚本`。
    *   点击 `创建脚本`。
    *   在脚本中定义一系列服务调用，例如：

    ```yaml
    alias: 观影模式
    sequence:
      - service: cover.close_cover
        target:
          entity_id: cover.bedroom_curtain
      - service: light.turn_on
        target:
          entity_id: light.bedroom_light
        data:
          brightness_pct: 20
      - service: media_player.turn_on
        target:
          entity_id: media_player.living_room_tv
    ```
    *   然后，在您的 DeepSeek 系统提示中，将 `观影模式 (scene.movie_night)` 修改为 `观影模式 (script.guan_ying_mo_shi)`，并添加相应的执行示例。
