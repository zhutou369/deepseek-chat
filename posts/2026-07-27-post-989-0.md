在日常使用中，频繁地打开应用、输入文字来与 AI 助手互动，有时会显得不够直接和高效。如果你希望能够像唤醒 Siri 一样，通过一个简单的操作就能与 DeepSeek AI 进行语音对话，那么 iPhone 的快捷指令功能将是你的理想选择。本文将详细指导你如何利用 DeepSeek API，结合 iPhone 快捷指令，打造一个专属的、一键唤醒的语音智能助手。

## 准备工作：获取 DeepSeek API Key

要让快捷指令能够与 DeepSeek 模型进行通信，你需要一个 DeepSeek API Key。这个 Key 是你访问 DeepSeek 强大 AI 能力的凭证。

1.  **注册并登录 DeepSeek 平台**：
    *   访问 `chat.deepseek.com` 或 DeepSeek 开发者平台。
    *   如果你还没有账户，请先注册并登录。
2.  **生成 API Key**：
    *   登录后，通常可以在用户设置或开发者控制台找到“API Keys”或类似的选项。
    *   点击“创建新 Key”或“Generate New Key”。
    *   请妥善保管你的 API Key，因为它具有访问你账户资源的权限。一旦生成，建议立即复制并保存到安全的地方，因为出于安全考虑，Key 通常只显示一次。

> **重要提示**：API Key 相当于你的账户密码，请勿泄露给他人或上传到公共代码库。

## iPhone 快捷指令核心逻辑设计

我们的目标是创建一个快捷指令，它能实现以下流程：

1.  **语音输入**：用户通过语音提问。
2.  **文本转写**：将用户的语音内容转写成文字。
3.  **API 请求**：将转写后的文字作为请求体，调用 DeepSeek 的 Chat Completion API。
4.  **接收响应**：获取 DeepSeek 返回的 AI 回复。
5.  **语音播报**：将 AI 的文字回复通过系统朗读出来。

这个流程将整个 DeepSeek 交互整合到一次点击或语音指令中。

## 创建 DeepSeek 语音助手快捷指令

现在，我们一步步来构建这个快捷指令。

1.  **打开“快捷指令”App**
    *   在 iPhone 上找到并打开“快捷指令”应用。
    *   点击右上角的“+”号创建一个新的快捷指令。
    *   点击“添加操作”。

2.  **获取用户语音输入**
    *   在搜索框中输入“听写文本”并选择该操作。
    *   配置“听写文本”：确保语言选择为“中文 (中国大陆)”或你常用的语言。
    *   这一步会将你的语音输入转换为文本。

    ![快捷指令听写文本](https://cdn.pixabay.com/photo/2016/11/29/05/45/apple-1867611_1280.jpg)
    *(示意图：快捷指令中的一个操作步骤)*

3.  **构建 DeepSeek API 请求**

    这一步是核心。我们需要设置一个 HTTP POST 请求来调用 DeepSeek 的 `/chat/completions` 接口。

    *   **添加“文本”操作（用于 API Key 和 URL）**
        *   再次点击“添加操作”，搜索并选择“文本”。
        *   将你的 DeepSeek API Key 粘贴到这个文本框中。稍后我们将通过“获取变量”来引用它。
        *   **再次添加“文本”操作**，这次输入 DeepSeek API 的 URL：`https://api.deepseek.com/chat/completions`

    *   **添加“字典”操作（用于构建请求体）**
        *   搜索并选择“字典”。
        *   我们需要构建一个 JSON 格式的请求体，包含 `model`、`messages` 和 `temperature` 等参数。
        *   点击“添加新项”，按以下结构添加键值对：

            | 键 (Key)   | 类型 (Type) | 值 (Value)                                     | 说明                                        |
            | :--------- | :---------- | :--------------------------------------------- | :------------------------------------------ |
            | `model`    | 文本        | `deepseek-chat` (或其他你希望使用的模型)     | 指定 DeepSeek 模型名称                      |
            | `messages` | 字典        | (点击添加新项，构建数组)                       | 对话历史，我们将把用户输入添加到这里        |
            |            | -           | `role` -> `system`                             | 系统提示，可自定义 AI 行为                  |
            |            | -           | `content` -> `你是一个乐于助人的AI助手。`      | 系统提示内容，可根据需求修改              |
            |            | -           | `role` -> `user`                               | 用户输入角色                                |
            |            | -           | `content` -> **`听写文本`的变量**              | 引用上一步的语音转写结果                    |
            | `stream`   | 布尔值      | `假`                                           | 设置为 `false` 以获取完整响应               |
            | `temperature` | 数字     | `0.7`                                          | 创造性控制，0-2 之间，0.7 是一个好的平衡点 |

        *   **如何引用“听写文本”的变量**：在 `content` 键的“值”部分，点击键盘上方的“魔法棒”图标，然后选择“听写文本”的输出。

    *   **添加“获取 URL 内容”操作**
        *   搜索并选择“获取 URL 内容”。
        *   **URL**：选择上一步设置的 DeepSeek API URL 文本框的变量。
        *   **方法**：选择 `POST`。
        *   **请求头**：
            *   点击“添加新请求头”。
            *   键：`Content-Type`，值：`application/json`。
            *   键：`Authorization`，值：`Bearer ` **（注意：`Bearer` 后有一个空格）**，然后点击魔法棒，选择你存储 API Key 的文本框变量。
        *   **请求体**：
            *   选择“JSON”。
            *   点击魔法棒，选择你上一步创建的“字典”变量。

4.  **处理 DeepSeek 响应**

    DeepSeek API 返回的响应通常是一个 JSON 对象。我们需要从中提取出 AI 的回复文本。

    *   **添加“获取字典值”操作**
        *   搜索并选择“获取字典值”。
        *   **字典**：选择上一步“获取 URL 内容”的输出。
        *   **键**：`choices`
        *   这一步将获取响应中的 `choices` 数组。

    *   **添加“获取列表项”操作**
        *   搜索并选择“获取列表项”。
        *   **列表**：选择上一步“获取字典值”的输出。
        *   **获取**：`第一个项目` (通常 DeepSeek 只返回一个 `choice`)。

    *   **再次添加“获取字典值”操作**
        *   **字典**：选择上一步“获取列表项”的输出。
        *   **键**：`message`

    *   **最后一次添加“获取字典值”操作**
        *   **字典**：选择上一步“获取字典值”的输出。
        *   **键**：`content`
        *   至此，你已经成功提取出 DeepSeek AI 的文字回复。

    ![快捷指令流程图](https://cdn.pixabay.com/photo/2017/08/07/22/07/laptop-2607909_1280.jpg)
    *(示意图：快捷指令的复杂逻辑处理)*

5.  **语音播报 AI 回复**

    *   **添加“朗读文本”操作**
        *   搜索并选择“朗读文本”。
        *   **文本**：点击魔法棒，选择你上一步获取到的 `content` 变量。
        *   你可以调整语速、音高和语言，让 AI 的声音更自然。

6.  **保存快捷指令并测试**
    *   点击右上角的“完成”保存你的快捷指令。
    *   给快捷指令一个容易识别的名称，例如“DeepSeek 语音助手”。
    *   在快捷指令列表中点击它进行测试。说出你的问题，听听 DeepSeek 的回复吧！

## 优化与高级技巧

### 1. 自定义系统提示 (System Message)
在构建请求体的字典操作中，你可以修改 `role: system` 下的 `content` 内容。例如，将其改为“你是一个专业的旅行规划师，每次回复都要包含一个建议的景点。”这将引导 DeepSeek 在每次对话中扮演特定角色。

### 2. 快捷指令启动方式

*   **添加到主屏幕**：
    *   长按快捷指令图标，选择“共享” -> “添加到主屏幕”，即可像应用一样快速启动。
*   **Siri 唤醒**：
    *   在快捷指令的设置中，可以录制一个自定义的 Siri 语音命令，例如“嘿 Siri，唤醒 DeepSeek”。
*   **轻点背面 (Back Tap)**：
    *   在“设置” > “辅助功能” > “触控” > “轻点背面”中，你可以设置双击或三击 iPhone 背面来运行这个快捷指令，实现无感唤醒。

### 3. 错误处理与用户反馈

为了更好的用户体验，可以添加一些错误处理机制：

*   **添加“如果”操作**：在“获取 URL 内容”之后，检查其状态码。如果不是 200，则显示一个错误通知。
*   **添加“显示通知”操作**：在语音播报之前或之后，显示一个简短的通知，例如“DeepSeek 正在思考...”或“DeepSeek 回复完毕”。

### 4. 模拟多轮对话

虽然当前快捷指令是单轮对话，但可以通过更复杂的逻辑来模拟多轮。例如，将每次对话的 `user` 和 `assistant` 消息存储在文本文件中，然后在下一次请求时读取并构建 `messages` 数组。这需要更复杂的快捷指令编程。
你可以参考 [/posts/deepseek-multi-turn-memory/](https://deepseek-website.com/posts/deepseek-multi-turn-memory/) 来理解多轮对话的原理，并尝试在快捷指令中进行模拟。
