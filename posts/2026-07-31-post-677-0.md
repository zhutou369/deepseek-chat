### 步骤 3：编写 DeepSeek API 调用脚本

现在，我们将编写一个 Python 脚本来读取导出的文本，并将其作为提示词发送给 DeepSeek API 进行扩展。

```python
import requests
import json
import os

# --- 配置您的 DeepSeek API 信息 ---
DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY", "YOUR_DEEPSEEK_API_KEY") # 建议从环境变量获取
DEEPSEEK_API_URL = "https://api.deepseek.com/chat/completions" # DeepSeek Chat API endpoint
MODEL_NAME = "deepseek-chat" # 使用 deepseek-chat 模型

# --- 文件路径配置 ---
INPUT_OUTLINE_PATH = "my_outline.md" # XMind导出的文件
OUTPUT_FULL_OUTLINE_PATH = "full_extended_outline.md" # DeepSeek生成的大纲保存路径

def read_outline_from_file(file_path):
    """从文件中读取XMind导出的纯文本大纲"""
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            return f.read()
    except FileNotFoundError:
        print(f"错误：文件 '{file_path}' 未找到。请检查路径。")
        return None

def call_deepseek_api(outline_text):
    """调用DeepSeek API扩展大纲"""
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}"
    }

    # 构建发送给DeepSeek的请求体
    # system_message：定义模型的角色和行为
    # user_message：提供XMind大纲并给出具体的扩展指令
    messages = [
        {
            "role": "system",
            "content": "你是一位专业的文章结构大纲扩展专家。你的任务是根据用户提供的大纲，将其详细扩展成一份层次分明、内容丰富的长文大纲。每个子主题下至少包含3-5个具体要点、论述方向或段落思路。请保持原有的层级结构，并在此基础上进行深入阐述和补充，确保总字数可支持一篇万字文章的写作。使用Markdown格式输出。"
        },
        {
            "role": "user",
            "content": f"请根据以下文章大纲进行详细扩展：\n\n{outline_text}\n\n要求：\n1. 保持并深化原有层级结构。\n2. 每个子主题下添加3-5个详细的论述要点或段落核心内容。\n3. 内容应具备学术深度和实用性。\n4. 使用Markdown格式输出。"
        }
    ]

    payload = {
        "model": MODEL_NAME,
        "messages": messages,
        "temperature": 0.7, # 控制生成内容的随机性，0.7是一个平衡值
        "max_tokens": 8000 # 根据需要调整，确保能够生成足够长的内容
    }

    try:
        response = requests.post(DEEPSEEK_API_URL, headers=headers, json=payload, timeout=120)
        response.raise_for_status() # 检查HTTP响应状态码
        result = response.json()
        
        # 提取模型生成的内容
        if result and result.get("choices"):
            return result["choices"][0]["message"]["content"]
        else:
            print("API响应中未找到生成内容。")
            return None
    except requests.exceptions.RequestException as e:
        print(f"调用DeepSeek API时发生网络或请求错误: {e}")
        return None
    except json.JSONDecodeError as e:
        print(f"解析API响应JSON失败: {e}")
        return None

def save_extended_outline(content, file_path):
    """将DeepSeek生成的大纲保存到文件"""
    try:
        with open(file_path, 'w', encoding='utf-8') as f:
            f.write(content)
        print(f"扩展大纲已成功保存到 '{file_path}'")
    except IOError as e:
        print(f"保存文件时发生错误: {e}")

if __name__ == "__main__":
    # 优先从环境变量读取API KEY
    if DEEPSEEK_API_KEY == "YOUR_DEEPSEEK_API_KEY" or not DEEPSEEK_API_KEY:
        print("警告：DeepSeek API 密钥未设置。请将其替换为您的实际密钥或设置 DEEPSEEK_API_KEY 环境变量。")
        exit()

    print(f"正在读取XMind导出大纲文件: {INPUT_OUTLINE_PATH}...")
    xmind_outline = read_outline_from_file(INPUT_OUTLINE_PATH)

    if xmind_outline:
        print("成功读取大纲。正在调用 DeepSeek API 进行扩展...")
        # 建议先在DeepSeek Chat (chat.deepseek.com) 测试提示词效果
        # 参考：[DeepSeek Chat 网页版基础使用](/posts/deepseek-chat-web-basics/)

        extended_outline = call_deepseek_api(xmind_outline)

        if extended_outline:
            save_extended_outline(extended_outline, OUTPUT_FULL_OUTLINE_PATH)
            print("任务完成！")
        else:
            print("未能从 DeepSeek API 获取到扩展大纲。")
    else:
        print("无法继续，因为未能读取输入大纲文件。")

```
**重要提示：** 在运行脚本前，请将 `YOUR_DEEPSEEK_API_KEY` 替换为您的实际 DeepSeek API 密钥，或者最好将其设置为环境变量 `DEEPSEEK_API_KEY`。

### 步骤 4：处理 DeepSeek 返回的扩展大纲

运行 Python 脚本后，DeepSeek 将根据您的 XMind 骨架和提示词生成一个详细的扩展大纲，并保存到 `full_extended_outline.md` 文件中。

1.  **打开生成的 Markdown 文件。** 您会发现每个子主题下都填充了更多的详细要点和思路。

3.  **进一步利用：** 这个详细大纲可以直接作为 Word 文档、Markdown 文档或任何其他内容创作工具的输入，极大地加速您的写作进程。

## 优化与高级技巧

为了获得更优质的扩展大纲，您可以尝试以下优化方法。

### 1. 精细化提示词（Prompt Engineering）

提示词是与 AI 交互的关键。您可以通过调整 `system` 消息和 `user` 消息中的指令，来引导 DeepSeek 生成更符合预期的大纲。

*   **指定输出格式：** 明确要求 DeepSeek 使用 Markdown 标题（`#`, `##`, `###`）进行结构化输出。
*   **字数与深度要求：** “确保总字数可支持一篇万字文章的写作”或“每个要点扩展至200字左右的段落思路”。
*   **风格与语气：** “请以学术报告的严谨风格扩展”、“请以科普文章的通俗易懂风格阐述”。
*   **添加上下文信息：** 如果您的主题比较专业，可以在提示词中提供一些背景信息或关键术语定义，帮助 DeepSeek更好地理解。
*   **在 DeepSeek Chat 网页版测试：** 建议先在 `chat.deepseek.com` 上直接粘贴您的 XMind 导出内容和提示词进行测试，观察其生成效果。这有助于您快速迭代和优化提示词，而无需频繁修改代码。您可以参考这篇教程了解 [DeepSeek Chat 网页版的基础使用](/posts/deepseek-chat-web-basics/)。

### 2. 迭代与修订

对于非常庞大或复杂的项目，一次性生成万字大纲可能不够理想。您可以考虑分阶段生成：

1.  **第一阶段：** 生成一个相对粗略的大纲，确保宏观结构正确。
2.  **第二阶段：** 针对每个主要章节，将其作为单独的输入再次调用 DeepSeek API 进行更深层次的扩展。这种多轮对话的方式，能让您更好地控制内容的生成深度。
    *   深入了解 DeepSeek 的多轮对话能力，请参考 [DeepSeek 多轮对话与记忆功能解析](/posts/deepseek-multi-turn-memory/)。

### 3. 多模型与参数选择

DeepSeek 平台可能提供多种模型。对于大纲扩展任务，`deepseek-chat` 通常是最佳选择。调整 `temperature` 参数可以影响生成内容的创造性：
*   `temperature` 接近 0：生成内容更保守、确定性更高。
*   `temperature` 接近 1：生成内容更具发散性、创造力更强。
对于大纲，通常 `0.5` 到 `0.7` 是一个不错的平衡点。

### 4. 结合 DeepSeek Chat 应用程序进行快速测试

除了网页版，您也可以考虑使用 DeepSeek 移动应用程序进行快速的提示词测试和内容生成，这在移动办公时尤其方便。了解更多，请查看 [DeepSeek 移动应用程序：随时随地智能对话](/posts/deepseek-mobile-app-chat/)。

## 常见问题与解决方案

*   **API 请求失败：**
    *   检查您的 `DEEPSEEK_API_KEY` 是否正确且有效。
    *   检查网络连接。
    *   确认 DeepSeek API URL (`DEEPSEEK_API_URL`) 是否正确。
    *   查看控制台输出的错误信息，可能是 `requests.exceptions.HTTPError`，意味着服务器返回了错误状态码（如 401 未授权，429 频率限制）。
*   **生成内容不符合预期：**
    *   **提示词优化：** 最常见的原因是提示词不够清晰具体。请重新审视 `system` 和 `user` 消息，加入更多约束和要求。
    *   **上下文不足：** 如果 XMind 导出的节点过于简短或模糊，DeepSeek 可能难以理解其深层含义。尝试在 XMind 中加入更详细的注释或在 `user` 消息中补充说明。
    *   **模型限制：** 某些高度专业化或涉及最新信息的内容，AI 可能存在知识边界。
*   **字数不足或过长：**
    *   **调整 `max_tokens`：** 在 API 请求的 `payload` 中调整 `max_tokens` 参数。一个 token 大致相当于半个中文字。8000 tokens 大约可生成 4000 汉字左右。
    *   **修改提示词：** 在 `system` 或 `user` 消息中明确要求生成内容的字数范围或每个要点的扩展深度。
