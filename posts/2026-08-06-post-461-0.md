即使没有预购的云服务器或GPU算力，你仍然可以快速搭建一个用于访问 DeepSeek API 的专属节点。利用华为云 ModelArts 的弹性 Notebook 服务，我们可以按需创建计算环境，部署一个简单的 API 代理服务，从而以极低的门槛和成本实现 DeepSeek API 的调用。本教程将引导你完成从环境搭建到服务部署的整个过程。

## 为什么选择华为云 ModelArts？

对于零算力基础的用户，ModelArts 提供了一个非常友好的入口：

*   **按需付费**：你可以根据实际使用时长付费，无需预购昂贵的固定算力资源。用完即释放，最大限度节省成本。
*   **集成开发环境**：Notebook 服务提供了基于 Jupyter 的交互式开发环境，预置了丰富的机器学习框架和Python环境，省去了繁琐的配置步骤。
*   **快速部署**：通过 Notebook 可以一键将代码部署为 Web 服务，对外提供 API 接口，无需复杂的容器化或运维知识。
*   **资源弹性**：可以根据需求选择不同的GPU或CPU资源配置，满足从测试到生产的不同需求。

## 准备工作：华为云与 DeepSeek 账号

在开始之前，请确保你已完成以下准备：

1.  **华为云账号**：注册并完成实名认证。这是使用华为云所有服务的基础。
2.  **DeepSeek API Key**：
    *   访问 [chat.deepseek.com](https://chat.deepseek.com/)。
    *   登录你的 DeepSeek 账号。
    *   在个人中心或 API 设置页面生成并复制你的 API Key。请妥善保管此 Key，因为它用于鉴权。

## 步骤一：创建 ModelArts Notebook 实例

1.  **登录华为云控制台**：
    在浏览器中输入 `console.huaweicloud.com`，使用你的华为云账号登录。

2.  **进入 ModelArts 服务**：
    在控制台首页搜索框中输入 "ModelArts"，点击搜索结果进入 ModelArts 控制台。

3.  **创建 Notebook 实例**：
    *   在 ModelArts 控制台左侧导航栏，选择 **开发环境** > **Notebook**。
    *   点击页面右上角的 **创建** 按钮。
    *   **配置实例参数**：
        *   **名称**：自定义一个易于识别的名称，例如 `DeepSeek-Proxy-Node`。
        *   **资源池**：选择 **公共资源池**。
        *   **资源规格**：根据你的预算和需求选择。对于初次尝试或轻量级使用，推荐选择较低配置，如 **CPU: 8核，内存: 64GiB** 或带有 **GPU: V100/A100 (1卡)** 的最低配置。注意，即使是 GPU 实例，在不运行任务时也只按 CPU 费用计费，但运行起来后 GPU 费用会增加。为零算力基础，我们暂时选用纯 CPU 即可。
        *   **存储类型**：默认即可，例如 **高性能**。
        *   **存储容量**：默认 100GB 通常足够。
        *   **镜像**：选择一个包含常用AI框架的镜像，例如 **Conda-Python3.9-PyTorch1.12-TensorFlow2.8**。
        *   **计费模式**：选择 **按需计费**。这是零算力用户避免预付费的关键。
    *   确认配置无误后，点击 **立即创建**。实例创建通常需要几分钟。

4.  **启动 Notebook 实例**：
    当实例状态变为“运行中”后，点击实例名称右侧的 **打开** 按钮，进入 JupyterLab 环境。

## 步骤二：环境配置与依赖安装

进入 JupyterLab 环境后，我们将进行必要的环境配置和依赖安装。

1.  **打开终端**：
    在 JupyterLab 界面的左侧文件浏览器中，点击 **文件** > **新建** > **终端**，打开一个新的终端窗口。

2.  **安装 Python 依赖**：
    我们的代理服务将使用 Flask 或 FastAPI 作为 Web 框架，并需要 `deepseek-python-sdk` 来调用 DeepSeek API。
    在终端中执行以下命令：

    ```bash
    pip install Flask deepseek-python-sdk uvicorn # 或者 fastapi
    ```

    这里我们选择 `Flask` 作为轻量级框架，`uvicorn` 作为异步 Web 服务器，以及 `deepseek-python-sdk`。如果你对 FastAPI 更熟悉，也可以选择安装 `fastapi`。

3.  **设置 DeepSeek API Key**：
    出于安全考虑，不建议将 API Key 直接写入代码。我们可以将其设置为环境变量。在终端中执行：

    ```bash
    export DEEPSEEK_API_KEY="你的DeepSeek_API_Key"
    ```
    **注意**：这里的 `export` 命令只在当前终端会话中有效。如果关闭终端或重启 Notebook，需要重新设置。在实际生产部署时，ModelArts 的 Web 服务部署配置中可以更持久地设置环境变量。

## 步骤三：编写 DeepSeek API 代理服务

现在，我们将编写一个简单的 Python 脚本，作为 DeepSeek API 的代理服务。这个服务会接收外部请求，然后使用你的 API Key 调用 DeepSeek 官方 API，并将结果返回。

1.  **创建 Python 文件**：
    在 JupyterLab 中，点击 **文件** > **新建** > **Python 3 (IPyKernel)**，创建一个新的 Notebook。将其重命名为 `app.py`（如果想直接写 Python 文件），或者在 Notebook 中直接编写代码。这里我们假设直接创建一个 `app.py` 文件。

    ```python
    # app.py
    import os
    from flask import Flask, request, jsonify
    from deepseek import Deepseek

    app = Flask(__name__)

    # 从环境变量获取DeepSeek API Key
    DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY")
    if not DEEPSEEK_API_KEY:
        raise ValueError("DEEPSEEK_API_KEY environment variable not set.")

    # 初始化Deepseek客户端
    deepseek_client = Deepseek(api_key=DEEPSEEK_API_KEY)

    @app.route('/chat', methods=['POST'])
    def deepseek_chat_proxy():
        try:
            data = request.get_json()
            messages = data.get('messages')
            model = data.get('model', 'deepseek-chat') # 默认为deepseek-chat
            temperature = data.get('temperature', 0.7)

            if not messages:
                return jsonify({"error": "messages parameter is required"}), 400
            if not isinstance(messages, list):
                return jsonify({"error": "messages must be a list of message objects"}), 400

            # 调用 DeepSeek API
            response = deepseek_client.chat.completions.create(
                model=model,
                messages=messages,
                temperature=temperature
            )

            # 返回DeepSeek的响应
            return jsonify(response.model_dump()), 200

        except Exception as e:
            app.logger.error(f"Error in deepseek_chat_proxy: {e}")
            return jsonify({"error": str(e)}), 500

    @app.route('/', methods=['GET'])
    def health_check():
        return "DeepSeek Proxy Service is running!", 200

    if __name__ == '__main__':
        # 在本地开发环境中运行，端口通常默认为5000
        # 在ModelArts部署时，Web服务会配置端口，这里不需要显式指定
        app.run(host='0.0.0.0', port=5000)
    ```

    这个简单的 Flask 应用暴露了一个 `/chat` 接口，接收包含 `messages` 和 `model`（可选）的 JSON 请求，然后将其转发给 DeepSeek API。我们还添加了一个 `/` 健康检查接口。

    如果你对 DeepSeek API 的消息格式不熟悉，可以参考这篇入门教程：[DeepSeek Chat Web 基础教程](/posts/deepseek-chat-web-basics/)。

## 步骤四：部署为 Web 服务

现在，我们将把编写好的代理服务部署为 ModelArts 的 Web 服务，使其可以通过公网访问。

1.  **停止 Notebook 实例**：
    回到 ModelArts 控制台的 Notebook 实例列表。为了部署 Web 服务，通常需要先停止当前的 Notebook 实例。点击实例名称右侧的 **停止** 按钮。

2.  **创建 Web 服务**：
    *   在 ModelArts 控制台左侧导航栏，选择 **部署上线** > **Web 服务**。
    *   点击页面右上角的 **创建** 按钮。
    *   **配置服务参数**：
        *   **名称**：自定义服务名称，例如 `DeepSeek-API-Proxy`。
        *   **ModelArts 资源类型**：选择 **Notebook 代码**。
        *   **Notebook 实例**：选择你之前创建并已停止的 Notebook 实例（`DeepSeek-Proxy-Node`）。
        *   **代码目录**：通常是 `/home/ma-user/work/`，这里应包含你的 `app.py` 文件。
        *   **启动文件**：填写 `app.py`。
        *   **启动参数**：这里是关键，你需要告诉 ModelArts 如何启动你的 Web 服务。使用 `uvicorn` 来运行 Flask 应用，命令如下：
            ```bash
            uvicorn app:app --host 0.0.0.0 --port 8000
            ```
            `app:app` 表示从 `app.py` 文件中找到名为 `app` 的 Flask 应用实例。`--host 0.0.0.0` 允许外部访问，`--port 8000` 是服务监听的端口。
        *   **资源规格**：选择适合的 CPU 或 GPU 规格。再次强调，对于代理服务，纯 CPU 规格通常足够，而且更经济。选择一个较低配的 CPU 规格即可。
        *   **副本数量**：默认 1 即可。
        *   **环境变量**：**非常重要**！在这里设置你的 `DEEPSEEK_API_KEY`。点击 **添加**，键入 `DEEPSEEK_API_KEY`，值为你的 DeepSeek API Key。这样，你的 Key 将在服务启动时被安全注入到环境变量中。
        *   **高级配置**：默认即可。
    *   确认配置无误后，点击 **立即创建**。服务部署需要一些时间。

## 步骤五：测试 DeepSeek 专属节点

服务部署成功后，其状态将变为“运行中”，并会生成一个**访问地址**。

1.  **获取访问地址**：
    在 Web 服务列表页，点击你的服务名称，进入详情页。复制 **访问地址** (形如 `https://your-service-id.apigw.cn-east-3.huaweicloud.com`)。

2.  **测试服务**：
    使用 `curl` 命令或 Postman、Insomnia 等 API 测试工具进行测试。

    **测试健康检查接口：**

    ```bash
    curl https://your-service-id.apigw.cn-east-3.huaweicloud.com/
    ```
    预期响应：`DeepSeek Proxy Service is running!`

    **测试 DeepSeek Chat 代理接口：**

    ```bash
    curl -X POST \
      https://your-service-id.apigw.cn-east-3.huaweicloud.com/chat \
      -H 'Content-Type: application/json' \
      -d '{
        "messages": [
          {"role": "user", "content": "你好，请简单介绍一下自己。"}
        ],
        "model": "deepseek-chat",
        "temperature": 0.7
      }'
    ```

    预期响应将是 DeepSeek API 返回的 JSON 格式内容，其中包含模型生成的回复。例如：

    ```json

            "role": "assistant"

        }

      "created": 1701234567,
      "id": "chatcmpl-...",
      "model": "deepseek-chat",
      "object": "chat.completion",
      "usage": {
        "completion_tokens": 40,
        "prompt_tokens": 14,
        "total_tokens": 54
      }
    }
    ```
    至此，你已成功在华为云 ModelArts 上拉起了一个 DeepSeek 专属节点，可以随时通过这个访问地址来调用 DeepSeek API 了！

## 成本考量与资源释放

*   **按需计费**：ModelArts 的 Notebook 和 Web 服务都支持按需计费，这意味着只有当你的实例或服务处于“运行中”状态时才会产生费用。

*   **观察费用**：在华为云控制台的 **费用中心** 可以查看你的消费明细。
