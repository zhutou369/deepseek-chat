在日常办公中，我们经常需要在表格中处理大量文本数据，或在文档中进行内容创作、总结和润色。如果能直接在 WPS Office 环境中调用强大的大模型能力，无疑将极大提高工作效率。本教程将引导您如何在 WPS 表格和 WPS 文字中集成 DeepSeek 大模型 API，实现表格数据智能化处理和文档内容自动化生成。

## 1. 准备工作：获取 DeepSeek API 密钥

要调用 DeepSeek 大模型，您需要一个 API 密钥。

1.  **访问 DeepSeek 平台**: 打开浏览器，访问 [platform.deepseek.com](https://platform.deepseek.com)。
2.  **注册/登录**: 如果您还没有 DeepSeek 账户，请完成注册。已有账户的用户直接登录。
3.  **生成 API 密钥**: 登录后，通常会在控制台或个人设置中找到“API 密钥”或“API Keys”选项。点击“创建新密钥”，为您的密钥命名（例如：WPS Integration），然后复制生成的密钥。请务必妥善保管此密钥，因为它拥有您账户的访问权限。

    > **提示**: 关于 DeepSeek Chat 的基本操作，您可以参考这篇教程：[DeepSeek Chat 网页版基础教程：从零开始与AI对话](/posts/deepseek-chat-web-basics/)。

## 2. 在 WPS 中启用开发者工具

## 3. WPS 表格接入 DeepSeek 大模型：自定义函数

在 WPS 表格中，我们将创建一个自定义函数 (UDF)，可以直接在单元格里调用 DeepSeek API。

### 3.1 编写 VBA 宏代码

1.  **打开 VBA 编辑器**: 在“开发工具”选项卡中，点击“Visual Basic”按钮，这将打开 VBA 编辑器。
2.  **插入模块**: 在 VBA 编辑器的左侧项目窗口中，右键点击您的工作簿（例如 `VBAProject (您的文件名.et)`），选择“插入” -> “模块”。
3.  **粘贴代码**: 将以下 VBA 代码复制并粘贴到新创建的模块中。

    ```vba
    Option Explicit

    ' 声明 DeepSeek API 密钥 (请替换为您自己的密钥)
    Private Const DEEPSEEK_API_KEY As String = "YOUR_DEEPSEEK_API_KEY_HERE"
    Private Const DEEPSEEK_API_ENDPOINT As String = "https://api.deepseek.com/v1/chat/completions"

    ' 自定义函数：调用 DeepSeek Chat 模型
    ' prompt: 用户的请求文本
    ' model: 使用的模型名称，默认为 "deepseek-chat"
    ' temperature: 生成内容的随机性，0.1-1.0，默认为 0.7
    Function DEEPSEEK_CHAT(prompt As String, Optional model As String = "deepseek-chat", Optional temperature As Double = 0.7) As String
        Dim xhr As Object
        Dim jsonBody As String
        Dim responseText As String
        Dim result As String

        On Error GoTo ErrorHandler

        ' 检查 API 密钥是否已设置
        If DEEPSEEK_API_KEY = "YOUR_DEEPSEEK_API_KEY_HERE" Or DEEPSEEK_API_KEY = "" Then
            DEEPSEEK_CHAT = "#API_KEY_ERROR! 请在VBA代码中设置您的DeepSeek API密钥。"
            Exit Function
        End If

        ' 创建 XMLHTTP 请求对象
        Set xhr = CreateObject("MSXML2.XMLHTTP")

        ' 构建请求体 JSON
        jsonBody = "{""model"": """ & model & """,""messages"": [{""role"": ""user"", ""content"": """ & Replace(prompt, """", """""") & """}],""temperature"": " & Replace(CStr(temperature), ",", ".") & "}"

        ' 打开 POST 请求
        xhr.Open "POST", DEEPSEEK_API_ENDPOINT, False ' False 表示同步请求
        xhr.SetRequestHeader "Content-Type", "application/json"
        xhr.SetRequestHeader "Authorization", "Bearer " & DEEPSEEK_API_KEY

        ' 发送请求
        xhr.Send jsonBody

        ' 检查响应状态
        If xhr.Status = 200 Then
            responseText = xhr.responseText
            ' 解析 JSON 响应
            result = ParseDeepSeekResponse(responseText)
            DEEPSEEK_CHAT = result
        Else
            DEEPSEEK_CHAT = "#ERROR! DeepSeek API 返回错误: " & xhr.Status & " - " & xhr.responseText
        End If

        Exit Function

    ErrorHandler:
        DEEPSEEK_CHAT = "#VBA_ERROR! " & Err.Description
    End Function

    ' 辅助函数：解析 DeepSeek API 响应 (简化版)
    ' 实际应用中可能需要更健壮的 JSON 解析库
    Function ParseDeepSeekResponse(jsonString As String) As String
        Dim startPos As Long
        Dim endPos As Long
        Dim content As String

        ' 寻找 "content": "..." 部分
        startPos = InStr(jsonString, """content"":""")
        If startPos > 0 Then
            startPos = InStr(startPos + Len("""content"":"""), jsonString, """")
            If startPos > 0 Then
                endPos = InStr(startPos + 1, jsonString, """")
                If endPos > 0 Then
                    content = Mid(jsonString, startPos + 1, endPos - startPos - 1)
                    ' 简单处理转义字符，如 \" 变为 "
                    ParseDeepSeekResponse = Replace(content, "\""", """")
                    ParseDeepSeekResponse = Replace(ParseDeepSeekResponse, "\n", Chr(10)) ' 换行符
                    ParseDeepSeekResponse = Replace(ParseDeepSeekResponse, "\t", Chr(9)) ' 制表符
                    ' 更多转义字符处理可在此添加
                    Exit Function
                End If
            End If
        End If
        ParseDeepSeekResponse = "#PARSE_ERROR! 无法解析 DeepSeek 响应。" & jsonString
    End Function
    ```
    > **重要**: 将代码中的 `YOUR_DEEPSEEK_API_KEY_HERE` 替换为您在第一步中获取的 DeepSeek API 密钥。

### 3.2 在 WPS 表格中使用自定义函数

1.  **保存宏**: 在 VBA 编辑器中，点击“文件” -> “保存”，并将工作簿保存为支持宏的格式（例如 `.etm` 或 `.ets`）。
2.  **在单元格中调用**: 返回 WPS 表格。现在您可以在任何单元格中像使用普通函数一样调用 `DEEPSEEK_CHAT` 函数了。

    *   **示例 1：总结单元格内容**
        假设 `A1` 单元格中有一段长文本。在 `B1` 单元格输入：
        ```excel
        =DEEPSEEK_CHAT("请总结以下内容："&A1)
        ```
    *   **示例 2：翻译文本**
        在 `C1` 单元格输入：
        ```excel
        =DEEPSEEK_CHAT("请将以下中文翻译成英文："&A1)
        ```
    *   **示例 3：指定模型和温度**
        ```excel
        =DEEPSEEK_CHAT("给我一个关于人工智能的创意点子。", "deepseek-coder", 0.9)
        ```

通过这种方式，您可以快速对表格中的文本数据进行批量处理，例如情感分析、分类、摘要、翻译等。

## 4. WPS 文档接入 DeepSeek 大模型：文本处理宏

在 WPS 文字中，我们可以创建宏来处理选定的文本或生成新内容，例如总结、润色或生成段落。

### 4.1 编写 VBA 宏代码

1.  **打开 VBA 编辑器**: 在 WPS 文字的“开发工具”选项卡中，点击“Visual Basic”按钮。
2.  **插入模块**: 在 VBA 编辑器的左侧项目窗口中，右键点击您的文档（例如 `VBAProject (您的文件名.wps)`），选择“插入” -> “模块”。
3.  **粘贴代码**: 将以下 VBA 代码复制并粘贴到新创建的模块中。

    ```vba
    Option Explicit

    ' 声明 DeepSeek API 密钥 (请替换为您自己的密钥)
    Private Const DEEPSEEK_API_KEY As String = "YOUR_DEEPSEEK_API_KEY_HERE"
    Private Const DEEPSEEK_API_ENDPOINT As String = "https://api.deepseek.com/v1/chat/completions"

    ' 宏：总结选定文本
    Sub SummarizeSelectedText()
        Dim selectedText As String
        Dim prompt As String
        Dim result As String

        On Error GoTo ErrorHandler

        ' 获取当前选定的文本
        selectedText = Selection.Text

        If Trim(selectedText) = "" Then
            MsgBox "请先选中一段文本。", vbExclamation
            Exit Sub
        End If

        ' 构建请求 DeepSeek 的提示
        prompt = "请简洁地总结以下文本内容：" & selectedText
        result = CallDeepSeekAPI(prompt)

        ' 将总结结果插入到选定文本之后
        If Left(result, 1) <> "#" Then ' 如果不是错误信息
            Selection.Collapse Direction:=wdCollapseEnd ' 将光标移动到选定文本末尾
            Selection.TypeText Text:=vbCrLf & "【总结】" & result & vbCrLf
        Else
            MsgBox result, vbCritical
        End If

        Exit Sub

    ErrorHandler:
        MsgBox "发生错误: " & Err.Description, vbCritical
    End Sub

    ' 宏：润色选定文本
    Sub PolishSelectedText()
        Dim selectedText As String
        Dim prompt As String
        Dim result As String

        On Error GoTo ErrorHandler

        selectedText = Selection.Text

        If Trim(selectedText) = "" Then
            MsgBox "请先选中一段文本。", vbExclamation
            Exit Sub
        End If

        prompt = "请对以下文本进行润色，使其表达更流畅、专业，并保持原意：" & selectedText
        result = CallDeepSeekAPI(prompt)

        If Left(result, 1) <> "#" Then
            Selection.Text = result ' 替换选定文本
        Else
            MsgBox result, vbCritical
        End If

        Exit Sub

    ErrorHandler:
        MsgBox "发生错误: " & Err.Description, vbCritical
    End Sub


    ' 辅助函数：实际调用 DeepSeek API 的逻辑
    Private Function CallDeepSeekAPI(prompt As String, Optional model As String = "deepseek-chat", Optional temperature As Double = 0.7) As String
        Dim xhr As Object
        Dim jsonBody As String
        Dim responseText As String

        ' 检查 API 密钥是否已设置
        If DEEPSEEK_API_KEY = "YOUR_DEEPSEEK_API_KEY_HERE" Or DEEPSEEK_API_KEY = "" Then
            CallDeepSeekAPI = "#API_KEY_ERROR! 请在VBA代码中设置您的DeepSeek API密钥。"
            Exit Function
        End If

        Set xhr = CreateObject("MSXML2.XMLHTTP")

        jsonBody = "{""model"": """ & model & """,""messages"": [{""role"": ""user"", ""content"": """ & Replace(prompt, """", """""") & """}],""temperature"": " & Replace(CStr(temperature), ",", ".") & "}"

        xhr.Open "POST", DEEPSEEK_API_ENDPOINT, False
        xhr.SetRequestHeader "Content-Type", "application/json"
        xhr.SetRequestHeader "Authorization", "Bearer " & DEEPSEEK_API_KEY

        xhr.Send jsonBody

        If xhr.Status = 200 Then
            responseText = xhr.responseText
            CallDeepSeekAPI = ParseDeepSeekResponse(responseText)
        Else
            CallDeepSeekAPI = "#ERROR! DeepSeek API 返回错误: " & xhr.Status & " - " & xhr.responseText
        End If
    End Function

    ' 辅助函数：解析 DeepSeek API 响应 (与表格代码相同，可复用)
    Private Function ParseDeepSeekResponse(jsonString As String) As String
        Dim startPos As Long
        Dim endPos As Long
        Dim content As String

        startPos = InStr(jsonString, """content"":""")
        If startPos > 0 Then
            startPos = InStr(startPos + Len("""content"":"""), jsonString, """")
            If startPos > 0 Then
                endPos = InStr(startPos + 1, jsonString, """")
                If endPos > 0 Then
                    content = Mid(jsonString, startPos + 1, endPos - startPos - 1)
                    ParseDeepSeekResponse = Replace(content, "\""", """")
                    ParseDeepSeekResponse = Replace(ParseDeepSeekResponse, "\n", Chr(10))
                    ParseDeepSeekResponse = Replace(ParseDeepSeekResponse, "\t", Chr(9))
                    Exit Function
                End If
            End If
        End If
        ParseDeepSeekResponse = "#PARSE_ERROR! 无法解析 DeepSeek 响应。" & jsonString
    End Function
    ```
    > **重要**: 同样，将代码中的 `YOUR_DEEPSEEK_API_KEY_HERE` 替换为您在第一步中获取的 DeepSeek API 密钥。

## 5. 进阶技巧与注意事项

*   **API 密钥安全**: 在实际生产环境中，不建议将 API 密钥硬编码在 VBA 脚本中。可以考虑从环境变量或加密配置文件中读取，但对于简单的 WPS 宏，直接设置通常是可以接受的。
*   **错误处理**: 提供的代码包含了基本的错误处理，但您可以根据需要增加更详细的错误日志或用户提示。
*   **异步请求**: VBA 中的 `MSXML2.XMLHTTP` 默认是同步请求 (`False`)，这意味着在收到 DeepSeek 响应之前，WPS 界面会冻结。如果处理大量文本或网络延迟较高，这会影响用户体验。实现异步请求会更复杂，需要事件处理，但能提升用户体验。
*   **JSON 解析**: 示例中的 JSON 解析器非常简化，只提取 `content` 字段。更复杂的 DeepSeek 响应（例如函数调用、多轮对话等），可能需要更健壮的 JSON 解析库或手动解析更多字段。
    > **了解多轮对话**: 若您对DeepSeek的多轮对话能力感兴趣，可参考：[DeepSeek 多轮对话记忆功能详解](/posts/deepseek-multi-turn-memory/)。
*   **模型选择**: DeepSeek 提供了 `deepseek-chat` 和 `deepseek-coder` 等模型。根据您的任务选择合适的模型可以获得更好的效果。
*   **速率限制与配额**: DeepSeek API 有请求速率限制和使用配额。请注意您的使用量，避免因超出限制而导致请求失败。
